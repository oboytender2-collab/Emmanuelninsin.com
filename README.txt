EMMANUEL OSEI KOJO NINSIN — WEBSITE GALLERY UPLOAD

CONTENTS
- images/ : 10 optimized photos
- gallery.html : a standalone responsive gallery page

IMPORTANT
This package is prepared for uploading to your existing GitHub Pages website.
It does not automatically modify your live website.

OPTION A — Add photos to your existing Gallery page
1. Open your GitHub repository.
2. Open the folder where your website's main index.html is located.
3. Create/open a folder named images.
4. Upload all 10 files from the images folder in this ZIP.
5. Edit your existing Gallery page and use the matching image paths, e.g. images/gallery-01.jpg.

OPTION B — Publish this as a separate gallery page
1. Upload the images folder and gallery.html into the same folder as your site's index.html.
2. Open: https://oboytender2-collab.github.io/Emmanuelninsin.com/gallery.html

If your website files live inside a subfolder in the repository, upload the files there instead.
Keep filenames exactly as provided so the page can find the pictures.
